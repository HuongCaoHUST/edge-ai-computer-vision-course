# Lab 5 · FPS và độ trễ

## Mục tiêu

- Đo pipeline với warm-up và số lần lặp cố định.
- Báo cáo mean, std, p50, p95, p99 và FPS.
- So sánh kết quả giữa các thiết bị và số thread.

## Sản phẩm đầu ra

Benchmark có `--tag` theo từng thiết bị và phân tích nút thắt cổ chai.
