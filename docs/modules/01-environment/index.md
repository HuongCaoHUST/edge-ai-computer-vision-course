# Lab 1 · Chuẩn bị môi trường

## Mục tiêu

- Tạo môi trường Python và cài dependency.
- Kiểm tra PyTorch, torchvision và OpenCV.
- Phân biệt quy trình chạy trên máy huấn luyện, Raspberry Pi và Jetson.

## Yêu cầu đầu vào

- Python 3.10 trở lên.
- Git và terminal cơ bản.
- Máy có thể chạy Python; GPU là tùy chọn.

## Sản phẩm đầu ra

- Ảnh chụp phiên bản công cụ hoặc file ghi kết quả kiểm tra.
- Môi trường `.venv` hoạt động.

Tiếp tục với [Nội dung & thực hành](guide.md).
