# Lab 2 · Nội dung 2 · Huấn luyện

## Mục tiêu

Sau khi hoàn thành, bạn có thể:

- Kiểm tra môi trường làm việc.
- Tạo cấu trúc thư mục dự án.
- Chạy chương trình mẫu và đọc kết quả.
- Ghi chép để tái lập và nộp bài.

## Yêu cầu

- Python 3.10 trở lên.
- Git.
- Trình soạn thảo mã nguồn, ví dụ VS Code.
- Kiến thức terminal cơ bản.

## Cấu trúc bài làm

```text
lab1/
├── README.md
├── src/main.py
└── output/result.txt
```

Thời lượng đề xuất: **60–90 phút**.

Tiếp tục với [Hướng dẫn thực hành](guide.md).
