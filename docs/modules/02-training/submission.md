## Đóng gói

Từ thư mục cha của `lab1`:

```bash
zip -r lab1-<mssv>.zip lab1 -x "lab1/__pycache__/*" "lab1/.venv/*"
```

!!! note "Lưu ý"
    Thay `<mssv>` bằng mã số sinh viên và không đưa khóa API hoặc thông tin nhạy cảm vào bài nộp.
